# To-Do-Ever

## 📌 Project Overview
To-Do-Ever is a Python terminal application designed to help users organize their daily tasks.  
The application allows users to add, remove, view, prioritize, and complete tasks. It also includes a simple AI logic to suggest tasks based on priority and upcoming deadlines.


## ⚙ Features
- Add tasks with **name**, **priority** (high, medium, low), and **deadline** (YYYY-MM-DD format)
- Remove tasks from the list
- View pending tasks
- Mark tasks as completed
- View completed tasks
- Suggest tasks that are high priority or have deadlines within 7 days
- Interactive menu in the terminal
